tikjot 1.0: out of beta, free and open source.

## New

- tikjot is out of beta. Thank you to everyone who tested it and sent feedback.
- The source code is public on GitHub under the GPL-3.0 licence. Anyone can read how tikjot handles your data.
- Ideas and questions now have a home in GitHub Discussions. Bugs still go to Issues, or use Settings › General › Report an issue.

## Fixed

- A thin line no longer shows at both ends of the "What are you working on?" field in the menu bar.

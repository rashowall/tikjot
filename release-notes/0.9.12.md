Ready for a move from Jira Data Center to Jira Cloud, a recovery window if tikjot can't start, and VoiceOver labels.

## Improved

- Moving from Jira Data Center to Jira Cloud: in Settings › Jira, on the Cloud site, choose "Replaces an older Jira". Worklogs that were copied to Cloud are linked, not counted twice — even if the Cloud site already brought in its history. Work you haven't sent to the old Jira yet moves to the same task on Cloud and you send it from there; the preview tells you if a task isn't on Cloud, so you can pick another one.
- If tikjot can't open its data at start, a window says what happened and offers to restore the latest snapshot or a backup file, instead of a bare English alert.
- VoiceOver reads the Day blocks (state, overlap, lock) and offers move, resize, split, task, Jira and delete actions; Week, Month, Statistics, Unsent and the widget have spoken labels.

## Fixed

- Searching for the same task again no longer saves it again each time.

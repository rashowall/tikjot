Fixes after moving from Jira Data Center to Jira Cloud: no duplicate projects, and nothing stuck on the old Jira.

## Fixed

- After moving from Jira Data Center to Cloud, projects no longer show twice: a project tikjot made for the Cloud site's key joins the one you already had, also when Cloud dropped the underscore from the key (OPS_DESK → OPSDESK). A project lists each key once, and the old key copied to Cloud where Cloud has only the new one is removed.
- Work left on the old Jira after the move no longer makes a day look "not in Jira" with nothing to send: if Cloud has the same task, it moves there; otherwise Review asks you to pick its task in the new Jira.

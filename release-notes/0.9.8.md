Settings no longer get stuck after importing history, and every date field now opens tikjot's own calendar.

## Improved

- Date fields (import history, work time, opening balance, absences, connecting Jira) open the same calendar as the date picker in Day, instead of the system one. Days you can't pick are faded; arrow keys and Return work too.

## Fixed

- Picking a date in Settings › Jira › "Import history from" could hide Settings, and when you opened them again the import dialog was stuck on "Importing…" and the window couldn't be closed. Picking a day now closes the calendar first and only then starts the import. Thanks for the report!
- The import dialog showed the previous start date instead of the one you just picked.

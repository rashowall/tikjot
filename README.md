# tikjot

**Jira time tracking from your Mac menu bar.** A small Mac app that tracks your day as it happens and turns it into
tidy Jira worklogs — checked by you before anything is sent. Free, private by design.

→ **[tikjot.com](https://tikjot.com)**

tikjot is in a **private beta**. Releases (signed and notarized by Apple) appear under
[Releases](https://github.com/rashowall/tikjot/releases); the app updates itself from there.
The source code will be published in this repository at launch, under the GNU GPL v3.0.

Found a bug? Open an issue. A security problem? See [SECURITY.md](SECURITY.md).
